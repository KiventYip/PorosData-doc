# Blog

This section complements the main guides with shorter, time-stamped notes: release highlights, design and engineering commentary, and pointers when a full manual chapter would be disproportionate. The site is published in English only; each post is a single Markdown file under `docs/blog/posts/`.

**Relative to the guides**, procedural pages sit in [Quick Start](../get_started/quickstart.md); framing and vocabulary sit in [Design Philosophy](../community/design-philosophy.md). **Research-style narrative**—for example [Research Review](posts/2026-05-06-research-review.md) and [Design Insights](posts/2026-05-06-design-insights.md)—is authored here rather than in the manuals.

**Relative to the changelog**, [Changelog](../community/changelog.md) records versioned, factual changes. The blog may expand on motivation, trade-offs, and links without restating every changelog line.

An RSS feed for posts is generated when the site is built with **`CI=true`** (as in the published pipeline). A local `mkdocs serve` without that flag may omit the RSS plugin; that is expected.

Useful adjacent pages: [Changelog](../community/changelog.md) · [Contributing](../community/contributing.md)
