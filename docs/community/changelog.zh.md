# 更新日志

本页记录 PorosData 面向外部用户可见的文档和交付说明变化，适合用于跟踪产品说明是如何逐步完善的。

## 记录原则

本页主要记录会影响外部理解或交付使用方式的变化，例如：

- 文档结构调整
- 推荐流程变化
- 交付范围或结果解释方式变化
- 面向外部用户的重要说明新增

内部实验、临时笔记和历史审计归档，除非改变了公开口径，否则不在这里展开记录。
