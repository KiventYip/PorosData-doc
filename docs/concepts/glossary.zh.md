# 术语表

本页汇总 PorosData 文档中反复出现的核心术语，帮助读者在工作流、工具页和交付说明之间保持统一理解。
{: .lead}

## 核心模块

### Parser

上游提取阶段，用于把原始论文转换为可继续处理的文本块、图片、图注和基础元数据。

### Processor

质量整理阶段，用于清理解析结果中的噪音，使内容达到后续可用状态。

### Designer

结构化交付阶段，用于把稳定输入组织成全文结果、结构化 JSON 和多模态索引。

## 交付分层

### `raw`

源数据层，用于保留原始论文和上游解析结果，便于追溯与复查。

### `processed`

中间结果层，用于存放清洗后的输出和处理报告。

### `structured`

最终交付层，用于存放全文结果、结构化结果和多模态资产。

## 输出类型

### `full_text`

面向阅读和人工复核的全文交付形式。

### `datamining`

面向结构化抽取、检索和入库的交付形式。

### `multimodal`

面向图文关联的交付形式，用于把正文中的图表引用与实际图片资产对应起来。

## 常见字段与概念

### `doc_id`

文档编号，用于组织输出目录并保持交付结构一致。

### Caption

图或表附带的说明文字，通常也是后续复核和抽取的重要信息来源。

### Asset Anchor

用于把正文中的图表引用稳定连接到实际资产文件的索引关系。

### `processing_report`

批处理摘要文件，用于记录输出状态、运行进度和质量复核线索。

### 学术原子性

一种处理原则，强调在整理过程中尽量保留科研内容的原始语义、结构线索与上下文关系。
