## 6.3 citation / ref 问题

当前 citation 处理不是完全失败，而是**协议不统一**。

### 已有进展

- 多数正文数字引用已从 `[1]`、`[2,3]` 规整为 `ref[1]`、`ref[2][3]`
- 未发现 `wordref[1]`、`ref[1]word` 这类明显粘连脏数据

### 仍然存在的问题

部分正文仍保留原始 bracket citation，而不是统一为 `ref[...]`，典型包括：

- `[11e22]`
- `[23e26]`
- `[27e30]`
- `[11,13,18e22,31]`

这说明当前 citation 规范化对以下情形覆盖不够：

- 范围引用
- 混合列表与范围
- 连字符/区间变体

### 结论

- `ref` 协议已部分建立，但**还没有全量稳定统一**
- 对 `Designer` 来说，这会影响引用识别、切分和结构化映射

---

## 6.4 LaTeX 字符与命令污染

人工抽查确认，当前仍存在多类 LaTeX 级污染：

| 文档 | 典型问题 |
|------|------|
| `00017` | `\mathrm{Ii}`、`\textsf { u }`、`\Gamma`、`${ \sf B }_{2} { \sf O }_{3}` |
| `00001` | `$Z \mathbf{r} -$`、`\mathbf{X} -ray`、`\DeltaNb {- Y}` |
| `00010` | `$\tt Fe { \mathrm - } \tt B$`、`[11e22]` |
| `00014` | `Z { \mathbf { r } }`、异常下标与命令碎片 |

这类问题会带来两类风险：

- 渲染/解析层风险：LaTeX 命令不规范、命令碎裂、括号错置
- 语义层风险：元素、材料名、物理量被错误编码成噪音符号

---

## 6.5 语义级 OCR 误译

你指出的案例判断是准确的：

- `$Z \mathbf{r} -$ and Pd-based bulk ...`

这类问题不只是“空格没清干净”，而是**语义/术语恢复问题**。其正确目标更接近：

- `Zr-based and Pd-based bulk metallic glasses`

同类问题还包括：

- `Z \Gamma -` 应恢复为 `Zr-`
- `Ni` 被污染成 `\DeltaNb`
- `X-ray` 被异常编码为 `\mathbf{X} -ray` 或更糟的变体

### 结论

这类问题不能只靠通用空格压缩解决，必须引入：

- 领域术语词表
- 合金/元素白名单
- 上下文驱动的语义修复规则

## 9. 建议修复步骤

## 9.1 第一步：修正审计脚本口径

- 修改 `_has_unbalanced_dollars()`，忽略 `\$`
- 审计报告中区分“脚本命中”与“人工确认”
- 去掉主目录与 `papertest` 的重复统计，输出唯一文档视角摘要

## 9.2 第二步：补齐 citation 归一规则

- 统一处理 `[n-m]`、`[n,m]`、`[11e22]`、`[11,13,18e22,31]`
- 统一转为 `ref[11][12]...[22]` 或项目约定的稳定协议
- 严禁改写文末参考文献列表项

## 9.3 第三步：做元素/组成式专项修复

- 对 `Zr`、`Cu`、`Ag`、`Pd`、`La`、`Al`、`Ce` 等建立白名单
- 处理 `Z r`、`C u`、`A g`、`_ { 4 0`、`\mathrm { Z r` 等高频模式
- 对组成式和下标进行局部结构修复，而不是整段激进替换

## 9.4 第四步：做语义级术语恢复

- 建立 `X-ray`、`Zr-based`、`Pd-based`、`bulk metallic glass` 等领域短语规则
- 对 `$Z \mathbf{r} -$ and Pd-based bulk` 这类模式做上下文语义修复
- 把 `\Gamma`、`Ii`、`\DeltaNb` 之类异常字符纳入语义回退表

## 9.5 第五步：回归复验

每轮修复后建议至少执行：

```bash
porosdata-processor --enable-evaluation --force-reprocess
python scripts/audit_aiready_data.py
```

复验时至少检查：

- `00010`：确认 `\$` 不再误报
- `00012`、`00013`、`00014`：确认元素与下标残留显著下降
- `00017`：确认 LaTeX 命令污染被压制
- `00001`：确认 `Zr-based` / `X-ray` 类语义问题改善
