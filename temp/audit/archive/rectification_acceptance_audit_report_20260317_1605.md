## 6. 补丁修复（16:10 追加）

发现 `_repair_semantic_latex_pollution()` 中 `\mathbf` 正则未容忍 OCR 空格（原始文本为 `\mathbf { r }`，正则期望 `\mathbf{r}`），已将所有 `\mathbf` 正则加入 `\s*` 容忍：

```python
# 修复前
r'\\mathbf\{([a-z])\}'
# 修复后
r'\\mathbf\s*\{\s*([a-z])\s*\}'
```

修复后 00001 文档中 12 处 `\mathbf` OCR 污染中 11 处已正确清除。

**剩余 2 处说明**：
- `$\mathbf{\sigma}$`：合法物理符号（加粗应力张量），正确保留
- 00001 item 21 `$Z \mathbf{r}`：原始 `$\begin{array}{r}...` array 环境公式在公式修复管线中被错误重组产生的"幽灵"输出，属于公式结构修复预存 bug
