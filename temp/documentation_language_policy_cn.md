# 文档语言规范

[English Version](documentation_language_policy.md)

## 目标

所有持续维护的项目文档都应提供两份版本：

- 英文主文档
- 中文对应文档

## 命名规则

- 英文文档保留规范文件名。
- 中文对应文档在同名基础上于 `.md` 前追加 `_cn` 或 `_CN`。
- 除非明确面向中文阅读路径，否则跨文档链接默认优先指向英文主文档。

## 适用范围

本规范适用于仓库中持续维护的文档，包括：

- 根目录项目文档
- `docs/` 下的使用指南、架构说明、治理文档
- `scripts/` 下的审计报告与操作说明类 Markdown 文档

## 历史文档

历史审计归档允许保留旧措辞和旧路径，以保证可追溯性；但一旦进入维护更新，应按双语命名规则补齐对应版本。

## 维护要求

新增或更新持续维护文档时，应遵循：

1. 先更新英文主文档。
2. 再创建或更新带 `_cn` 或 `_CN` 后缀的中文对应文档。
3. 在条件允许时，为中英文版本补充互链。
