# LaTeX 公式 OCR 冗余空格清洗 - 完整修复方案

本方案整合作用域隔离、流水线规则、安全边界与测试用例，可直接作为 **LLM 指令** 或 **开发者 Spec** 使用。

---

## 一、角色与任务

**角色定位**：精通 LaTeX 语法与学术规范的后处理专家。

**任务**：修复 OCR 识别引入的非语义空格，还原公式的语义连贯性。

**设计原则**：语义优先、白名单驱动、幂等性、防御性回滚。

---

## 二、作用域识别 (Scope Management)

在执行任何合并前，将公式划分为两个区域：

### 2.1 激进修复区 (Aggressive Zone)

| 属性 | 说明 |
|------|------|
| **范围** | `\mathrm{...}`, `\mathbf{...}`, `\mathsf{...}`, `\mathit{...}`, `\ce{...}`, `\unit{...}` 及其内部嵌套的 `{...}` |
| **特性** | 支持递归；处理嵌套时**由内向外** |
| **策略** | 默认字符间距为 OCR 冗余，执行「语义坍缩」 |

### 2.2 普通区 (Zone-O)

| 属性 | 说明 |
|------|------|
| **范围** | 上述字体/化学命令之外的 `$...$` 空间 |
| **核心原则** | **修数不修字**：仅合并纯数字，禁止合并字母变量 |

---

## 三、三阶段修复流水线 (The Pipeline)

### Phase 1: 结构归一化 (Structural Normalization)

**执行顺序**：在激进区与 Zone-O 的**全量范围**内执行。

| 步骤 | 规则 | 示例 |
|------|------|------|
| 1.1 | 索引收紧 | `^ { ... }` → `^{...}`，`_ { ... }` → `_{...}` |
| 1.2 | 符号贴合 | `^{- 1}` → `^{-1}`，`_{ - i }` → `_{-i}` |
| 1.3 | 静态保护 | 锁定 `\cite{...}`, `\ref{...}`，以及 `~`, `\quad`, `\,`，禁止修改 |

### Phase 2: 语义坍缩 (Semantic Collapsing)

**仅在激进区内**，按 **A → B → C** 顺序、**由内向外** 递归执行：

| 模式 | 规则 | 示例 |
|------|------|------|
| **A (化学元素)** | `[A-Z] \s+ [a-z]` → 合并 | `Z r` → `Zr`，`P d` → `Pd` |
| **B (白名单单位/函数)** | 在大括号 `{` 后、索引符 `^`/`_` 后或独立词块时，匹配白名单并合并 | 见下表 |
| **C (复合单位)** | 修复斜杠两侧碎字符 | `K / m i n` → `K/min`，`m / s` → `m/s` |

**模式 B 白名单**：

| 类别 | 内容 |
|------|------|
| 单位 | nm, mm, μm(um), kg, ps, eV, keV, GPa, MPa, kPa, at.%, wt.% |
| 函数 | sin, cos, tan, exp, log, ln, min, max, lim, dim, det |

**模式 C 与 B 执行顺序**：先执行模式 C（复合单位），再执行模式 B（剩余单位/函数），避免重复或冲突。

### Phase 3: 数值修复 (Numerical Fixing)

**全量范围**（含 Zone-O）执行：

| 步骤 | 规则 | 示例 |
|------|------|------|
| 3.1 | 多位整数 | 合并连续数字间空格 | `2 0 0` → `200`，`7 0` → `70` |
| 3.2 | 浮点数 | 仅当 `.` 两侧均为数字时合并 | `0 . 5` → `0.5`（排除 `0 \cdot 5`） |
| 3.3 | 下标数字 | `_{6 0}` → `_{60}` | 在 Phase 1 索引收紧后一并处理 |

## 四、安全边界与不可操作项

### 4.1 禁止合并

| 场景 | 示例 | 原因 |
|------|------|------|
| Zone-O 内字母乘法 | `$a \ b$` | 代表 `a × b` |
| 函数参数间距 | `S ( q )`，`g ( r )` | 函数参数可读性 |
| 引用内部 | `[4]`，`\cite{...}` | 引用格式 |

### 4.2 保留间距

| 场景 | 示例 | 原因 |
|------|------|------|
| 硬空格 | `70 ~ \mathrm{K}` | `~` 为不可断空格 |
| 二元运算符前后 | `+`, `-`, `=`, `\approx` 等 | 保持可读性 |
| `\text{...}` 内部 | 用户显式文本 | 不做语义推断 |

### 4.3 引用保护

禁止修改 `\cite{...}`, `\ref{...}` 内部的任何空格。

## 六、测试用例基准 (Benchmark)

```python
TEST_CASES = [
    # 嵌套单位
    (r'$26 \mathrm{ {n m}^{- 1} }$', r'$26 \mathrm{nm}^{-1}$'),
    # 化学/合金式
    (r'$\mathrm{ Z r_{6 0} T i_{2} C u_{2 0} N i_{8} A l_{10} }$',
     r'$\mathrm{Zr_{60}Ti_{2}Cu_{20}Ni_{8}Al_{10}}$'),
    # 函数合并
    (r'$\mathrm{s i n} \theta$', r'$\mathrm{sin} \theta$'),
    # 复合单位
    (r'$v = 1 0 \mathrm{ K / m i n }$', r'$v = 10 \mathrm{K/min}$'),
    (r'$20 \mathrm{ m / s }$', r'$20 \mathrm{m/s}$'),
    # Zone-O 修数不修字
    (r'$a \ b = 0 . 5$', r'$a \ b = 0.5$'),
    # 独立元素
    (r'$\mathrm{P d}_{40} \mathrm{C u}_{30}$', r'$\mathrm{Pd}_{40} \mathrm{Cu}_{30}$'),
]
```

## 七、与现有代码集成

### 7.1 集成位置

在 `steps.py` 的 `local_text_compression`（或等效的 `compress_formula_content`）中，建议顺序：

1. **Phase 1**：结构归一化（索引收紧、负号贴合、保护 `\cite`/`\ref`/`~` 等）
2. **Phase 2**：仅在激进区内，由内向外递归：
   - 模式 C（复合单位）
   - 模式 B（单位/函数白名单）
   - 模式 A（化学元素）
3. **Phase 3**：全量数值修复（多位整数、浮点数、下标数字）

### 7.2 激进区识别示意

```python
AGGRESSIVE_COMMANDS = (r'\mathrm', r'\mathbf', r'\mathsf', r'\mathit', r'\ce', r'\unit')
# 递归提取各命令的 {...} 内部，由最内层 { 开始处理
```

### 7.3 幂等性与回滚

- 每步执行前可保存快照；若 `_validate_latex_structure` 校验失败则回滚。
- 修复后再次运行应得到相同结果。
